# FE Template
## Commands

### Lint commands

- Run eslint
  ```bash
  yarn lint
  ```
- Run eslint with fixing
  ```bash
  yarn lint:fix
  ```

### Run commands
```bash
yarn dev
```

### Build and serve commands

```bash
yarn build

// to run the built project
yarn serve
OR
yarn serve --host 0.0.0.0 --port 3000
```

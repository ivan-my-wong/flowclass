## Sample Component that use tailwind and Shadcn UI
This component using tailwind and [Shadcn UI](https://ui.shadcn.com/docs/installation/next) library.
[Shadcn UI](https://ui.shadcn.com/docs/installation/next) is UI library that build with Radix UI. It's very easy to use and we can customize it.

We can use tailwind by using this component in our project. 
Or we can migrate other component by implement tailwind class directly in existing component.
